Mini Project- Prompt Lab
Compare LLM Strategies on a Task
Mini Project 1 · Week 5 deliverable · ~5-8 hours across 3 days.
A small integrative build that exercises everything you learned
in W1-W5.
What you're building
A small notebook (or script) that compares four prompting
strategies on the same task, and tells you which one wins —
with numbers, not opinions.
The task: extract three structured fields from a job posting
snippet. Specifically:
company — the company doing the hiring
role — the job title
years_experience_required — the minimum experience required (integer)
You'll run all four strategies against 10 sample snippets, score
the results against a reference set, and write a 1-page reflection
on what you found.
Why this exists
By the end of W5 you've touched a lot — system prompts, async
pipelines, FastAPI services, cost tracking, golden sets, LLM-as-judge.
But you've never built one thing that uses all of it.
MP1 is that one thing. The point isn't to learn anything new. It's
to feel comfortable composing what you already know.
It also gives you something concrete to point at when someone asks
"how do you compare prompting strategies?" — a question that
comes up forever in this work.
The four strategies
You'll implement four prompting strategies. They are deliberately
different in shape:
All four use the same model (gpt-4o-mini) and the same
temperature (0.0). Only the prompt differs. That's the variable
you're isolating.
What you need to do
Step 1 — Read the data (15 min)
Load data/job_snippets.jsonl (10 entries) and
data/golden_set.jsonl (the ideal extractions). Skim a few
entries. Notice that some are clean ("Acme Corp seeks a Senior
Engineer with 5+ years"), some are messy ("We want a builder, ~3
years"), and some are intentionally ambiguous.
Step 2 — Write the four prompts (45 min)
Write four prompt variants in prompts.py (or as cells in your
notebook). Each prompt should accept a single job snippet and
return a JSON-like response.
Keep prompts focused. The point isn't to write the best prompt
of each kind — it's to write a clear example of each kind. A
beginner-level zero-shot prompt is fine if it's actually zero-shot.
Step 3 — Wire up async batching (60 min)
Run all 10 snippets × 4 strategies = 40 LLM calls. Do this in
parallel using the asyncio + httpx pattern you built in W2.
Capture for each call:
The strategy name
The snippet ID
The model's raw response
The parsed extraction (or None if parsing failed)
Cost in USD
Latency in seconds

The first two are deterministic — just compare strings (case
insensitive, trim whitespace). The third uses gpt-4o as judge

Step 6 — Write your 1-page reflection (30 min)
In mp1_writeup.md, answer in your own words:
1. Which strategy won, and on what dimension? (Accuracy?
Parse rate? Cost?)
2. What surprised you? Either a strategy worked better than
expected, or worse, or a specific snippet failed in a way
you didn't predict.
3. For *your* capstone domain, which strategy would you reach
for first? Justify in 2-3 sentences.
4. If you had another day, what would you try next? (Different
model? More snippets? Different prompts?)
That's the 1-page writeup. Don't pad it.
What "done" looks like
By the end you have, in your repo at mp1/:
